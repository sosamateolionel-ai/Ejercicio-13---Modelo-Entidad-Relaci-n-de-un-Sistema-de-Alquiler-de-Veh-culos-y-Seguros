# Ejercicio-13---Modelo-Entidad-Relaci-n-de-un-Sistema-de-Alquiler-de-Veh-culos-y-Seguros
Este ejercicio consiste en diseñar un modelo Entidad-Relación (DER) para un sistema de alquiler de vehículos y gestión de seguros[cite: 9]. El modelo permite administrar sucursales, vehículos, clientes, contratos de alquiler y la gestión de siniestros con aseguradoras[cite: 9].
